# e-Karşıt Takip GİB Senkronizasyon Eklentisi

1. Chrome/Edge'de `chrome://extensions` sayfasını açın.
2. Geliştirici modunu etkinleştirin.
3. **Paketlenmemiş öğe yükle** seçeneğiyle bu klasörü seçin.
4. GİB e-Karşıt portalında oturum açın ve bağımsız uygulama sayfasını açın.
5. Uygulamadaki GİB senkronizasyon/aktarım butonunu kullanın.

Eklenti GİB portalındaki mevcut tarayıcı oturumunu kullanır; kimlik bilgilerini saklamaz. GitHub Pages adresi `https://webtasarim70.github.io/karsit_takip/` olarak yapılandırılmıştır.
